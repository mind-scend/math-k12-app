### 2.2 MySQL Tables（用户与业务）

```sql
-- 用户账户表
CREATE TABLE users (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  openid VARCHAR(64) UNIQUE,  -- 微信openid
  phone VARCHAR(20) UNIQUE,
  nickname VARCHAR(50),
  avatar_url VARCHAR(255),
  role ENUM('student', 'parent', 'teacher', 'admin') DEFAULT 'student',
  grade VARCHAR(20),  -- 年级
  vip_status TINYINT DEFAULT 0,  -- 0:普通 1:月卡 2:年卡
  vip_expire_at DATETIME,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP
);

-- 会员套餐表
CREATE TABLE vip_packages (
  id INT PRIMARY KEY AUTO_INCREMENT,
  name VARCHAR(50),  -- "月度会员", "年度会员", "终身会员"
  price DECIMAL(10,2),
  duration_days INT,  -- 有效天数
  features JSON,  -- ["AI出卷无限", "错题本无限", "专属客服"]
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 订单表
CREATE TABLE orders (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  order_no VARCHAR(64) UNIQUE,
  user_id BIGINT,
  package_id INT,
  amount DECIMAL(10,2),
  status ENUM('pending', 'paid', 'refunded') DEFAULT 'pending',
  pay_time DATETIME,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  FOREIGN KEY (user_id) REFERENCES users(id)
);

-- 每日API调用统计（用于成本控制）
CREATE TABLE api_usage_stats (
  id BIGINT PRIMARY KEY AUTO_INCREMENT,
  user_id BIGINT,
  api_type VARCHAR(50),  -- 'ocr', 'llm', 'search'
  call_count INT DEFAULT 0,
  token_count INT DEFAULT 0,  -- LLM token数
  cost_amount DECIMAL(10,4),  -- 估算成本
  stat_date DATE,
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  UNIQUE KEY uk_user_api_date (user_id, api_type, stat_date)
);
```

## 三、API接口设计

### 3.1 API规范

**基础信息：**
- 域名：`https://api.mathapp.com/v1`
- 认证：JWT Bearer Token
- 格式：JSON
- 编码：UTF-8

**通用响应格式：**
```json
{
  "code": 0,
  "message": "success",
  "data": {...},
  "request_id": "uuid-xxx"
}
```

**错误码：**
| code | 说明 |
|------|------|
| 0 | 成功 |
| 1001 | 参数错误 |
| 1002 | 鉴权失败 |
| 2001 | 题库无匹配 |
| 3001 | LLM服务繁忙 |
| 3002 | OCR识别失败 |
| 4001 | 余额不足（VIP过期）|
