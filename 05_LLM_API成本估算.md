**月成本计算：**
```
百度数学OCR：5,000次/天 × 30天 × ¥0.015 = ¥2,250/月
有道智云：  5,000次/天 × 30天 × ¥0.012 = ¥1,800/月（推荐）
```

### 2.3 Token消耗分析

#### 场景1：拍照解题
```
输入（题目识别结果）：
"已知二次函数 y=ax²+bx+c 的图像开口向下，且经过点(1,0)和(2,1)，求a的取值范围。"

Prompt模板：
"作为资深数学教师，请解答这道题目：{题目内容}
请提供：1.详细解答步骤 2.多种解法 3.易错点提醒"

Token估算：
- 输入：约150字 = 200 Token
- Prompt：约100字 = 150 Token
- 输出：约500字 = 700 Token
- 单次总计：约1,050 Token
```

#### 场景2：举一反三（生成3道变式题）
```
Prompt模板：
"基于原题'{题目内容}'和答案'{答案}'，
生成3道同知识点变式题，难度分布：基础1道、进阶1道、挑战1道。
输出JSON格式..."

Token估算：
- 输入+Prompt：约400 Token
- 输出（3道题+答案）：约800 Token
- 单次总计：约1,200 Token
```

#### 场景3：AI生成诊断题
```
Prompt模板：
"学生画像：{薄弱点列表}，近期错题：{错题内容列表}
请生成4道专门针对这些思维盲区的诊断题..."

Token估算：
- 输入（学生画像+错题）：约600 Token
- 输出（4道题+解析）：约1,200 Token
- 单次总计：约1,800 Token
```

#### 场景4：智能组卷
```
Prompt模板：
"生成一份{年级}{学科}测试卷，要求：
- 总分100分，{时长}分钟
- {结构要求}
- 重点知识点：{知识点列表}
- 学生画像：{学习情况}"

Token估算：
- 输入（组卷参数）：约500 Token
- 输出（13道题+答案+评分标准）：约2,500 Token
- 单次总计：约3,000 Token
```

#### 场景5：AI批改
```
Prompt模板：
"请批改以下试卷答案：
学生答案：{学生作答}
标准答案：{参考答案}
知识点：{知识点列表}
请输出JSON格式的批改结果..."

Token估算：
- 输入（13道题的作答）：约1,000 Token
- 输出（批改+分析）：约1,500 Token
- 单次总计：约2,500 Token
```

### 4.2 盈亏平衡分析

```
┌─────────────────────────────────────────────────────────────────────────────┐
│                           盈亏平衡分析                                        │
│                                                                              │
│  假设：                                                                     │
│  - 免费用户：付费用户 = 9:1                                                   │
│  - 免费用户成本：¥0.10/人/月（OCR基础成本）                                   │
│  - 付费用户收入：¥29/人/月                                                    │
│  - 付费用户成本：¥2.60/人/月（API消耗+存储）                                  │
│                                                                              │
│  利润模型：                                                                  │
│  ┌───────────────────────────────────────────────────────────────────────┐  │
│  │  每人收入 = 付费用户占比 × 订阅收入                                       │  │
│  │          = 10% × ¥29 = ¥2.90                                           │  │
│  │                                                                       │  │
│  │  每人成本 = 免费用户占比 × 免费成本 + 付费用户占比 × 付费成本             │  │
│  │          = 90% × ¥0.10 + 10% × ¥2.60 = ¥0.09 + ¥0.26 = ¥0.35          │  │
│  │                                                                       │  │
│  │  利润率 = (收入 - 成本) / 收入 = (2.90 - 0.35) / 2.90 = 87.9%          │  │
│  └───────────────────────────────────────────────────────────────────────┘  │
│                                                                              │
│  结论：                                                                       │
│  ✅ 模型可行，利润率高达87.9%                                                 │
│  ✅ 关键在于提升付费转化率（目标15-20%）                                      │
│  ✅ 达到10万MAU时，月收入约¥29万，月利润约¥25万                               │
│                                                                              │
└─────────────────────────────────────────────────────────────────────────────┘
```

### 4.3 成本优化策略

| 优化方向 | 具体措施 | 预期节省 |
|---------|---------|---------|
| **Token优化** | 压缩Prompt，减少冗余输出 | 20-30% |
| **缓存策略** | 相似题目缓存LLM结果 | 40-50% |
| **批量采购** | OCR API包年折扣 | 25-35% |
| **模型选型** | 简单场景用低价模型 | 30-40% |
| **缓存复用** | 同知识点举一反三结果复用 | 15-25% |
